# Showcase — ngx-storage-manager-uceva

Aplicación Angular independiente que consume la librería **desde NPM** y usa solo su API pública.

## Ejecutar

```bash
cd showcase
npm install
npm start
```

Abrir http://localhost:4200

## Qué demuestra

- **LocalStorage:** guardar, leer, actualizar, eliminar y vaciar (texto, números y JSON).
- **Cache Storage:** crear cachés, guardar JSON, descargar recursos, leer, eliminar recursos, eliminar cachés y vaciar todo.
